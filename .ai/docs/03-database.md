# Database Design

## Conventions

- All primary keys are UUIDs generated by PostgreSQL `uuidv7()`
- Soft delete via nullable `deleted_at` timestamp on all tables
- All tables have `created_at` and `updated_at` timestamps
- All models inherit from `Base` in `app/db/base.py`

## Key Models

| Model | Key Fields |
|-------|-----------|
| User | id (UUID), user_id (unique editable, alphanumeric `[A-Za-z._-]`), email, full_name, password_hash, role_id, phone, birthday, address, job_title, company, join_date |
| Role | id, name, description, default (bool) |
| RolePermission | id, role_id, permission (`ns::action`), name, description |
| Category | id, name |
| Test | id, name, category_id, description, time_limit |
| Question | id, content, image_url, category_id, test_id, is_multiple_choice |
| AnswerOption | id, question_id, content, image_url, is_correct, explanation |
| Submission | id, user_id, question_id, answer_id, is_correct, answered_at, submission_history_id |
| SubmissionHistory | id, user_id, submission_count, submitted_at |
| UserTestAssignment | id, user_id, test_id, assigned_at, expires_at (unique: user_id+test_id) |
| RefreshToken | id, user_id, token, expires_at |
| Namespace | id, name, prefix, description |

## Migration Commands

```bash
# Create a new migration
alembic revision --autogenerate -m "description"

# Apply migrations
alembic upgrade head

# Rollback one migration
alembic downgrade -1

# View migration history
alembic history
```
